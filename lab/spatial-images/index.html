Spatial Depth AI Browser-only AI segmentation + depth parallax
Local AI prototype

Real browser models, no backend.

This version loads local browser AI models for background removal and depth estimation, removes the subject from the background plate, estimates depth, then animates multiple image planes for a more believable spatial effect.

Models Background removal uses RMBG-style processing. Depth estimation uses a Depth Anything pipeline in-browser. First run is heavy because the browser downloads the model weights.
Device note WebGPU is usually much faster. If unavailable, the app falls back to WASM, which still works but can be slower on large images.
